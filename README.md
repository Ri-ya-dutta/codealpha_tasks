# CodeAlpha Backend Development Internship Tasks

This repository contains my backend development projects completed as part of the **CodeAlpha Backend Development Internship Program**.

The projects focus on building REST APIs, database integration, authentication, authorization, and backend application functionality.

## Completed Tasks

| Task | Project | Description |
|---|---|---|
| 01 | URL Shortener | Converts long URLs into short links and redirects users. |
| 02 | Event Registration System | Manages events and user registrations. |
| 03 | Restaurant Management System | Manages restaurant operations, menus, reservations, orders, and inventory. |
| 04 | Job Board Platform | Manages employers, job listings, candidates, resumes, applications, and notifications. |

## Technologies Used

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JSON Web Tokens (JWT)
- **Security:** bcryptjs, role-based authorization
- **File Uploads:** Multer
- **Testing:** Postman, Thunder Client
- **Tools:** Git, GitHub, VS Code

*Individual tasks may use different technologies depending on their requirements.*

## How to Run

Each task contains its own server folder, dependencies, environment configuration example, and README with setup instructions.

Navigate to the relevant task's server directory, install its dependencies, configure the environment variables, and start the server using the instructions in that task's README.
